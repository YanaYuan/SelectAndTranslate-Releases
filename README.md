## ✨ 核心功能

- **智能划词翻译** — 在任何应用里选中文字，AI（GPT-4o）实时翻译弹窗。Alt+Q 开关。
- **截图 OCR 翻译** — 翻译图片、截图、视频字幕里的文字。Alt+W 截图翻译。
- **自动生词提取** — AI 从你的阅读记录中提取生词，带音标、词源、例句，可导出到 Anki（CSV）。
- **单词壁纸** — 把生词变成每小时轮换的桌面壁纸，看桌面时被动记忆。

- 所有生词数据存储在**本地**（SQLite），不上传任何服务器。
- 翻译时，选中的文本会发送到 OpenAI 的 GPT-4o API 进行翻译处理（联网所必需）。除此之外不向任何地方发送数据。
