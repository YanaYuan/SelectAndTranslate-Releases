## ✨ 核心功能

- **智能划词翻译** - AI驱动的实时翻译
- **自动生词提取** - 无需手动制作单词卡
- **单词壁纸** - 将生词变成桌面壁纸
- **间隔重复学习** - 科学记忆算法
- **截图翻译** - 支持图片文字翻译

## 🔧 安装步骤

1. 下载上方的安装包
2. 运行 `SelectAndTranslate_Setup_v1.0.0.exe`
3. 按提示完成安装
4. 首次启动后配置 Azure OpenAI API 密钥

## 📖 配置说明

应用需要 Azure OpenAI API 密钥：
- 打开应用设置
- 填入 API endpoint、API key 和 deployment name
- 保存后即可使用
